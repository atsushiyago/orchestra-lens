# Guided Listening Card template refinement

## Before → after

- Removed inferred `LEAD`, `SUPPORT`, and `FOUNDATION` roles.
- `mainVoice` is now emitted only when Hauptstimme evidence identifies a selected part.
- Other selected parts are displayed as `ALSO SOUNDING`, an objective active-part statement.
- The listener hint is reduced to one TV-readable grounded sentence.
- The duplicated footer tagline was removed; `GUIDED LISTENING` remains as the sole subtle mode indicator.

## Layout

The review page is exactly 1280 × 720. It uses a 34% insight column and 66% Smart Score column; the Verovio SVG is allowed up to 500px tall, approximately 10–15% larger than the prior 455px treatment.

## Score emphasis

No score-staff highlight is applied. The score remains an external, unedited Verovio SVG; this template does not assume stable staff-label element IDs or SVG coordinates. The warm Main Voice treatment in Orchestra X-Ray provides the visual connection without a brittle SVG hack.

## Evidence

Generated/objective: Listening Cue label and selected staves, Hauptstimme evidence, active MusicXML parts, and Verovio SVG.

Derived: the Main Voice presentation and concise listener hint, only when Hauptstimme evidence is available.

Curated: none.
